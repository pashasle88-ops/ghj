# Сайт "Перспектива ТЦ"

Сайт компании по обслуживанию систем безопасности.

## Демо
https://ваш-логин.github.io/имя-репозитория/

## Структура
- `index.html` - главная страница
- `proekt.html` - контент
- `proekt.css` - стили
- `proekt.js` - JavaScript
- `images/` - изображения

## Как добавить свои изображения
1. Создайте папку `images/`
2. Загрузите изображения
3. В коде замените пути `../проект 2/1.jpg` на `images/`
